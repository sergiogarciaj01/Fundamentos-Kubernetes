## 1️⃣ 💡 ¿Qué aprendí esta semana?

Configuré y preparé con éxito el laboratorio local de Kubernetes utilizando Docker Desktop y Git Bash en Windows. Logré sincronizar mi fork personal con el repositorio principal de la comunidad y validar el entorno con kubectl.

---

## 2️⃣ 🧩 ¿Qué fue lo más retador y cómo lo resolví?

Lo más retador fue organizar la estructura de git remotos (upstream y origin) en el entorno de trabajo para asegurarme de mantener la rama sincronizada sin sobrescribir los cambios de la comunidad.

---

## 3️⃣ 💻 Comandos y herramientas que practiqué

```bash
git clone https://github.com/karolrojas68/Fundamentos-Kubernetes.git
git remote add upstream https://github.com/edwinbermudez91/Fundamentos-Kubernetes.git
kubectl cluster-info
kubectl get nodes
```
